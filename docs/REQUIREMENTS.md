# [Github User Acitivity CLI — Requirements](github.com/gomahmoud/roadmap.sh-github-user-activity)

## 1. Project Overview

A command-line application for fetching github users acivity.

## 2. Scope

- Only fetching the latest activity of a user.

## 3. Functional Requirements

- FR-01: fetching user activity data.
- FR-02: parse user activity data.
- FR-03: format and display the user activity data.

## 4. Data Requirements

- event_id
- type_id
- actor_id
- actor_name
- repo_id
- repo_name

## 5. Input Validation and Errors

- Reject empty or whitespace-only usernames.
- Handle invalid arguments.
- Handle nonexistent usernames.
